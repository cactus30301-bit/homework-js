# - 과제 수행 과정 기록

이번에는 HTML과 CSS부터 만들어 보았다.  
역시나 쉽지 않았지만 그래도 계속 해봐야지 고군분투하는 시간 만큼 친해지겠구나 싶었다.  
이번에도 조바심이 나서 AI의 도움을 많이 받았으나,  
원하는 답이 나오지 않을 땐 수업 때 배운 내용을 뒤적거리며 마크업 해보았다...  
사실 HTML은 접근성을 하나도 고려하지 못했다...  
HTML 배울 때 가장 잘 하고 싶은 부분이었는데 아직도 제대로 하지 못하고 있어 많이 아쉽다.  

CSS부분은 위치 잡는게 아직 어렵다.  
AI한테 물어도 답답했던 부분이 수업 노트에는 잘 나와있어 문제를 해결할 수 있었다.  
list-style에 관한 부분이었는데, 자꾸 outside가 기본값이라 이걸 어떻게 li에 붙이지 하고 있었는데  
수업 노트를 보고 list-style 단축속성에 리스트 단추 이미지랑 insde만 붙이니 너무 간단히 해결됐다...  
정말 꼼꼼히 다 알려주셨구나 다시금 느꼈다.  

JS부분은 이번 주에 배운 내용으로 해보고 싶었는데 잘 되지 않았다.  
그래서 내 기대과는 다르게 코드가 또 약간 깔끔하지 못하게 나온것 같다...  
'코드도 사람이 만든거니까 훨씬 깔끔하고 단정한 방법이 있지 않을까 ?'  
하는 고민을 AI와 하니 그랬던걸까...  
느리더라도 스스로 생각하는 법을 많이 길러야겠다.  


# - 과제 코드 리뷰

아쉽게도 써먹지 못했다.

결국 구현해 내지 못했다.  
좀 더 해보면 될 것도 같은데... AI한테 과의존한 폐해다 정말.  

HTML, CSS에서는 여전히 flex, position, display 와 그들과 동행하는 속성들이 어렵게 다가왔다.  
flex를 줬다가 다른 자식때문에 relative를 주고 근데 또 즐겁게 CSS를 짜고 relative가 여기저기 있어서   
하나하나 지우다 보면 얘 없어도 되는거였네...? 하고 지우면 또 어딘가에서 문제가 연쇄적으로 터진다  
grid 완전 깔끔하다 이제부터 grid만 써야지라고 선언하고나서 시안대로 간격 조정하는게 어려워서  
여러번 배반을 당하고 있으나, 이번에도 grid로 시작했다가 돌고 돌아 flex, position으로 해결(?) 하였다...  
그치만 여전히 selection-info는 가자미눈을 하고 보게된다.  
오래걸릴 게 아니었는데 이상하게 오래 걸리고 계산기를 두드리며(!) 마크업을 했는데,
