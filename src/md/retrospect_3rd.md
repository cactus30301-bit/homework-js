# - 과제 수행 과정 기록

처음 번들러부터 설치하는게 맞나 싶지만 항상 초기설정 부터 삐걱대는건 여전하다.  
또 뭘 잘못했는지 모르겠지만 시작 부터 꽤 시간걸려 초기 설정이 끝났다.  
HTML로 구조부터 짜는데, 이 전에 배웠던 내용과 실습 코드를 뒤져가며 참고했다.  
다만 페이지네이션 부분은 여러 블로그들 기록을 살펴보다 더 헷갈려서 AI의 도움을 받았다.  
자바스크립트를 배우는 중이여서 자바스크립트를 많이 만져봐야 할텐데  
비교적 여러번 수행한 HTML, CSS, 경로설정 같은 부분에서도 여전히 막히고 있으니  
답답할 따름이다.

# - 과제 코드 리뷰

HTML코드를 짤 때 기초 토대를 잘 잡아두고 시작하고 싶었으나,  
이게 브라우저에서 잘 보일까 하는 걱정과 시간 안에 끝내야한다는 조바심에  
부실공사가 되지 않은 듯 싶다. HTML 대충 짜고 CSS도 급하게 들어와서  
제대로 갖추어지지 않은 구조에 CSS를 붙이려니 왔다가다 정신이 없다.

# - 회고

이번 한 주는 매일 복습을 착실히 수행하지 못했다.  
수업 시간 부터 이해가 좀 어려웠어서 복습할 때도 이해하면서 적어내려가는데  
많은 시간이 소요되었고, 오랜시간 깨 있다가 새벽이 오면 잡생각도 자연스레 많아졌다.  
차라리 이러고 있을바엔 얼른 자고 내일 수업에 조금이라도 정신차리고 있자는 마음이었다.  
하지만 밑빠진 독에 물붓기 같았고, 수업시간에 주어진 실습시간에는 떠오르는 코드 한 줄 없었다.  
분명 배운 내용이고 그대로 적는데도 구현이 안 되는게 많이 갑갑했다.  
여기서 부턴 좀 걱정이 깊어졌다.  
초반에도 버겁다고는 느꼈지만 이게 갈 수록 불어난다.  
오롯이 내가 다 감내하고 이겨내야 한다는 사실이 또 한번 갑갑하게 만든다.  
근데 또 무력감을 느끼고 있으니 왜 지금 그런걸 느끼나 싶고 진짜 미칠 노릇이다.  
과제는 아직 진행 중인데 완성할 수 있을지 모르겠다.  
여러 감정이 몰려오지만, 차라리 아무 기분도 안 느껴지면 좋겠다.
