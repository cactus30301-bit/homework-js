# - 과제 수행 과정 기록

html, css 부터 과제를 수행 해 봤으면 좋았을테지만,  
지난주 과제 수행 중에 너무 많은 좌절과 지침을 맛 보았으며...  
주말 간 다른 일정으로 인해 시간이 부족할 듯 하여 js 코드만 수정 해 보는 것으로 진행해보았다.

그 결과, 가장 먼저 제대로 짜여진 html과 css 코드의 중요성을 다시 한번 크게 깨우쳤으며,  
JavaScript를 배우는 와중에도 틈틈이 잘 짜여진 HTML, CSS 코드를 '보기'라도 해야겠다 싶었다.    
그리고 힘들 땐 다 포기하기 전에 한 모금의 성취감이라도 맛보게 해주어야 하구나 생각이 들었다.  
비록 기반 코드가 완벽했고, AI의 도움이 있긴 했지만,  
코드를 이해해 가며 짜볼 수 있는 기회가 주어져 약간의 희망을 느낄 수 있었다.  
dataset이랄지, 어떻게 탭 버튼과 탭 패널 간 액션 리액션을 연결할 것인지에 대한 로직을  
다시 한번 머릿 속에 새기는 계기가 되었다.    

되도록이면 배운 내용을 뒤져보거나 검색해보며 하나씩 해 보는 것이 좋고,  
내 머릿속에도 더 잘 남고, 나중을 위해서도 더 좋았겠지만...  
다른 한편으로는 심적, 시간적 여유가 부족해서 학창시절 공부하던 때 기억을 되살려  
정답이 있는 문제면 그냥 답지를 빨리 보고 습득하자 라는...  
정도에 벗어나는 마음으로 임했던 것 같다.   


# - 과제 코드 리뷰

초반부터 삐그덕 거리지 않으면 나 김효경이 아니다.  

addEventListener를 걸었는데 무반응이길래,  
찾아보니 addEventListener는 Element 전용이며, 나는 그것을 또 맛있게 냠냠쩝쩝 까 먹고  
querySelectorAll() 로 얻은 NodeList와  
getElementsByClassName() 으로 얻은 HTMLCollection에 신나게 갖다 붙이고 있었던 것이다.  
(아이고 이 감자야...)    
이로써 기초가 정말 중요하고, 그 기초를 복습하는 건 더 중요하다고 느꼈다...!!!    
모든 과목이 '이론과 실습' 순으로 진행되는 게 괜히 그러는게 아니다 이 말이야...  
과제를 통해 머리로 달달 외우는 식이 아닌 경험을 통한 습득이 이루어진 것에 큰 보람을 느꼈다.  

그리고 나서 tab button의 data-target과 tab panel의 id를 어떻게 연결할지 아무리 생각해도 모르겠어서...    
(이미 머릿속에 있는 지식을 꺼내오기란 왜 이렇게 어려운걸까요...)
```const targetSelector = button.dataset.target; ```  
```const targetPanel = document.getElementById(targetSelector);```
이 부분을 다시 알게 되었다.  
targetSelector 변수를 만드는데, 그게 ⭐dataset⭐의 target을 가리키게 하고,  
targetPanel 변수를 만들어서! getElementById로 선택된 targetSelector로 Id를 반환할 수 있게 한다!!
